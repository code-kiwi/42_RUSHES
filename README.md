# 42 Rushes

This repository contains projects developed during École 42 rushes.

## Context
Rushes are short, intensive group projects carried out over a limited time frame,
usually during a weekend. Teams are formed randomly, and the objective is to design,
implement, and deliver a working solution under strong time constraints.

## Content
- **Connect4**  
  Implementation of a Connect Four game featuring:
  - A playable user interface
  - An AI opponent

Additional rush projects may be added over time.

## Goals
- Practice rapid project structuring
- Collaborate efficiently with unfamiliar teammates
- Deliver functional software within strict deadlines

## Technical stack
Varies depending on the rush and project requirements.

## Notes
Rush projects prioritize adaptability, teamwork, and problem-solving over completeness
or long-term maintainability.
